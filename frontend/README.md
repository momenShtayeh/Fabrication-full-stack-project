# Fabrication Planning — Frontend

Angular 19 application for the fabrication planning backend. Setup, users and the list of screens are in the
[main README](../README.md).

```bash
npm install
npm start        # dev server on http://localhost:4200, /api is forwarded to the backend on port 8080
npm run build    # production build in dist/frontend/browser
```

The backend must be running (see the main README) before logging in.
